Scripta is a local-first Markdown note-taking app for Android, iOS, Linux, Windows and macOS. It is built for people who want fast, distraction-free writing without giving up control of their data.

Features:
- Markdown-first editor with a smart toolbar and an instant rendered reading view
- Edit and read-only modes, focus mode, and distraction-free writing
- Local SQLite storage with fast offline search
- Nested folders, favorites, pinning and drag-and-drop organization
- Optional self-hosted sync with last-write-wins conflict resolution
- Import and export complete backups as ZIP archives or plain Markdown
- Import an existing folder of Markdown files on Android using the Storage Access Framework
- Light and dark themes, multiple color palettes and font choices
- Desktop-class keyboard shortcuts on supported platforms
- No accounts, no ads, no analytics, no Google Play Services

Your notes stay on your device by default. Sync is optional and requires a server you configure yourself. Scripta does not operate a hosted sync service.
